# Changelog

## 0.1.0 (2026-11-18)
- First release, built on the Street Rod 2 SDL3 port v0.1.0.
- Enhanced races (town, street drag, drag strip, Mulholland, Aqueduct): high resolution, anti-aliasing, smooth
  motion, draw distance up to 120 segments, haze, enhanced mirror.
- `--aspect`, `--integer-scale`; gamepad; configurable gear keys.
- Launcher `Street Rod 2 Enhanced.exe`.
- `--classic`: the faithful port, unchanged.
